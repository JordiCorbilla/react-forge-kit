# UI Review

Use this skill when asked to audit, polish, critique, or improve an existing UI.

1. Inspect the route, components, styles, tokens, tests, and `DESIGN.md`.
2. Exercise the workflow at desktop and narrow widths; use screenshots or browser inspection when available.
3. Check task clarity, hierarchy, feedback, layout integrity, responsiveness, accessibility, consistency, and polish.
4. Test loading, empty, error, success, disabled, focus, long-content, and failed-action states where supported.
5. Report evidence-backed findings ordered by impact, with file/component references and concrete fixes.
