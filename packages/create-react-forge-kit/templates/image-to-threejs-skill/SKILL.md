# Image to Three.js

Use this skill only for 3D scenes, Three.js implementations, or reference-image conversions.

1. Inspect the reference for subject, shapes, depth, camera, palette, lighting, and important details.
2. Inspect the existing Three.js setup, asset pipeline, canvas sizing, and interaction model.
3. Keep geometry, materials, lighting, camera, and animation understandable and editable.
4. Match composition and silhouette before adding detail.
5. Handle resize, device pixel ratio, cleanup, and reduced motion where relevant.
6. Verify desktop and mobile rendering: nonblank canvas, correct framing, loaded assets, expected animation, and non-overlapping controls.
