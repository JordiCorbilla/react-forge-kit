# UI Design

Use this skill when building or substantially redesigning a web UI.

1. Inspect the existing app, tokens, routes, components, and screenshots first.
2. Read `DESIGN.md` at the project root when it exists. Create one for substantial work if it is absent.
3. Define the primary user task and make it the first-viewport signal.
4. Reuse existing primitives and use familiar, accessible controls with tooltips for unfamiliar icons.
5. Design loading, empty, error, success, disabled, hover, focus, validation, and long-content states.
6. Check narrow and wide layouts, wrapping, touch targets, keyboard navigation, and non-hover use.
7. Prefer meaningful imagery and product-specific hierarchy over generic gradients, ornamental blobs, nested cards, or oversized marketing composition.
8. Validate important screens in a browser or with screenshots when available.
