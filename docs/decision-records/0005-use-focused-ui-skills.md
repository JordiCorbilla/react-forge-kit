# 0005 Use Focused UI Skills

I keep UI guidance in several focused skills rather than one universal skill. Interface design, UI review, and image-to-Three.js work have different triggers, tools, and failure modes. Separate descriptions improve automatic selection and keep each skill small enough to apply without loading unrelated guidance.

The repository also includes a `DESIGN.md` template. A design brief records project-specific intent, while a skill describes a reusable workflow. Keeping those concerns separate lets the same skills work across different products.
